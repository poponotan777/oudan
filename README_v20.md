# オウダン v20:セールの周期を精査した「開催予定」表示と、あなたのステータス

## 変わること
1. **ホームに「今日のあなたの還元率(目安)」** を3サイト並べて表示
   - マイページの「あなたのステータス」(かんたん記入)から、今日のセール分を自動で足します
     - 楽天:SPU倍率/楽天カードで払う(5と0のつく日 +1倍)/会員ランク/買い回りの予定店舗数(マラソン・スーパーSALE中)
     - Yahoo!:ふだんの還元率/PayPayで払う(5のつく日 +4%)/ヤフショランク
     - Amazon:ふだんの還元率/プライム会員
   - 「今日のセール分も実質価格に含める」がONなら、検索結果・商品詳細・商品ページの **実質価格にも反映** します
   - 保存先はこの端末だけ(サーバーには送りません)
2. **「開催中・これからのセール」** を、2024〜2026年の実際の開催日を調べて作ったルールで自動表示
   - 「確定」(公式発表・シート登録)/「毎年同じ日程」(楽天スーパーSALE=3・6・9・12月の4日20時〜11日1:59)/「予想」(例年の傾向)を色分け
   - 本日終了は赤・明日終了はオレンジで目立たせる(これまでと同じルール)
   - スプレッドシートで取り込んだセールがあれば、それを優先して同じセールの予想は消します

## 手順

## 確認
1. ホームに「💰 今日のあなたの還元率(目安)」と「🗓 開催中・これからのセール」が出る
2. 「ステータスを設定」→ マイページで入力 →「保存する」→ ホームに戻ると数字が変わる
3. 5・15・25日(または5と0のつく日)に見ると、条件を入れた人だけ +1倍・+4% が足される
