# オウダン v23:アカウント機能の廃止(ログインなし・端末内の設定だけで使う形に)

## 外したもの
- ログイン・メール登録・パスワード・匿名ログイン
- リスト(気になる/定期購入)・📌追跡・値下がり通知・注目商品・「そろそろ切れる頃」
- 購入履歴・節約額・月別支出・「購入済み」バッジ
- オウダンポイント・毎日チェックイン・称号
- オウダン独自レビュー(購入者のみ投稿の仕組みが成り立たなくなるため)
- 🎯指値・JANコード協力ボタン・年代/性別の設定
- タブは **ホーム / 検索 / 設定** の3つに

## 残したもの(すべて端末内だけに保存。サーバーには送りません)
- あなたのステータス(SPU倍率・カード・PayPay払い・ランク・買い回り店舗数)
- 還元率の設定・お住まいの都道府県(送料の目安)・カード券種(還元率の目安)
- 最近見た商品・検索履歴
- 各モールのよく使うページ・クーポン/キャンペーンのリンク集

## 運営ページ(/crawl)を作り直し
- 以前の「ブラウザで開いて動かすクローラー」は、v18 の自動取得に置き換えたので外しました
- 代わりに **自動取得の実行記録(サイトごとのリクエスト数・書き込み件数・エラー)とDB容量のメーター** を表示します
- セール情報のスプレッドシート取り込み・手動登録はそのまま使えます
- 合言葉は v21 で入れた `ADMIN_KEY` になりました

## 手順
1. GitHub に **app フォルダ(丸ごと)・lib フォルダ・sql フォルダ・vercel.json** をドラッグ&ドロップ → Commit
2. Vercel が Ready になったら確認(下)
3. (任意)Supabase → Authentication →「Allow anonymous sign-ins」を **OFF**(もう使いません)
4. (任意)Vercel の環境変数 `NEXT_PUBLIC_CRAWL_KEY` は、`ADMIN_KEY` を入れてあれば削除してOK
5. (任意・元に戻せません)`sql/v23-cleanup-optional.sql` を流すと、使わなくなったテーブル
   (リスト・購入履歴・ポイント・レビュー・指値・旧価格記録など)を削除して容量を空けます。
   新しいプロジェクトで作り直した直後なら、データは無いので流して問題ありません

## 確認
1. 上のタブが「ホーム / 検索 / 設定」の3つ
2. 検索 → 商品を開く → 3サイト比較・こんな悩みに・共有ボタンが出て、リスト/指値/レビューは出ない
3. `/crawl` → 合言葉 → 実行記録とDB容量が出る
