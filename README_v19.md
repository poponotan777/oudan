# オウダン v19:商品ごとのページ(/p/…)と、新しい価格の見せ方

## 変わること
1. **商品ごとに自分のURLができます**:`https://oudan.vercel.app/p/4901301000001` のような形
   - Google検索・Xのリンクカード・共有の入口になります(Googleに知らせる「サイトマップ」も自動で作ります)
   - 中身は自動取得(v18)のDBから作るので、見られるたびに楽天・Yahoo!・Amazonへ問い合わせません(1時間ごとに作り直し)
   - トップから商品を開いたときも、アドレス欄がこのURLに変わるので、そのままコピーして共有できます
2. **価格推移グラフをやめて、3サイトの「今の価格」と「どのくらい安いか」を並べます**
   - 各サイトごとに:今いくら/実質いくら/**90日の中央値より何%安いか**/**3か月で何番目に安いか**
   - 価格を出すところ(検索結果・商品詳細・商品ページ)は、**必ず楽天・Yahoo!・Amazonの3つを並べます**。まだ見つかっていないサイトは「未取得」と出し、そのサイトで探すボタンを出します
3. 検索結果のカードにも3サイトの小さな価格表を出します。DBにある他サイトの価格で、足りないサイトを埋めます(「◯時点」と表示)
4. **Amazonを有効にしました**(タグ `popo-kaiteki-22`)。検索時のAmazon表示は、同じキーワードなら1時間まとめて使い回します
5. 商品説明から自動で判定した「こんな悩みに」を表示します

## 手順
※ v18(自動取得)が入って、1回以上動いていること。SQLはありません

### ① Vercel の環境変数を追加
Vercel → oudan → Settings → Environment Variables で追加(値はチャットに貼らないでください)

| 変数名 | 値 |
|---|---|
| `AMAZON_ENABLED` | `true` |
| `AMAZON_CLIENT_ID` | Creators API の Credential ID |
| `AMAZON_CLIENT_SECRET` | Creators API の Credential Secret |
| `AMAZON_CREDENTIAL_VERSION` | `3.3` |
| `AMAZON_PARTNER_TAG` | `popo-kaiteki-22` |
| `SITE_ORIGIN` | `https://oudan.vercel.app` |

### ② GitHub にアップロード
zip の中の **app フォルダ(丸ごと)** と **lib フォルダ** をドラッグ&ドロップ → Commit
(環境変数を先に入れておけば、このアップロードで自動的に反映されます)

### ③ 確認
1. Vercel の Deployments が **Ready(緑)**
2. `https://oudan.vercel.app/sitemap.xml` を開く → `/p/…` のURLがたくさん並んでいればOK
3. その中の1つを開く → 3サイトの価格と「中央値より◯%安い」「3か月で◯番目に安い」が出る
4. トップで検索 → カードに「楽天/Yahoo!/Amazon」の小さな価格表が出る → タップするとアドレス欄が `/p/…` に変わる
5. 記録がまだ7日分に満たない商品は「記録◯日分(集計中)」と出ます(自動取得を続けると埋まっていきます)

## 知っておくこと
- **「中央値」「何番目」は記録が7日以上ある商品だけ**に出します(少ない記録で言い切らないため)
- Amazonの価格はAPIの決まりで「時点」を必ず表示しています。Amazonの商品画像は、リンクカード(OGP)には使いません
- 価格推移・買い時を表示するサイトにAmazonのリンクを置くことは、アソシエイトの規約で「別途合意」が必要とされている点は、引き続きご注意ください(以前お伝えした内容)
