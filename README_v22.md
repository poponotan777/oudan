# オウダン v22:トップに「お得・急上昇・おすすめ」

## 変わること
ホームの「本日の値下げピックアップ」「楽天のおすすめ」「Yahoo!で人気の定番商品」を、
自動取得のDBから選ぶ **3つのタブ** に置き換えます(どの商品も3サイトの価格つき・タップで商品ページへ)。

| タブ | 選び方 |
|---|---|
| 📉 お得 | どれかのサイトで、**90日の中央値より8%以上安い**商品(記録7日以上・2日以内に更新・300円以上)。値下がり幅が大きい順 |
| 🚀 急上昇 | 楽天・Yahoo!・Amazonのランキングで**順位が大きく上がった/新しくランク入りした**商品(今日・昨日) |
| 🏆 おすすめ | **有名ブランド**でランキング入りしていて、**★4以上・レビュー30件以上**の商品 |

- 2サイト以上で比べられる商品を優先して並べます
- 30分ごとに作り直します(見られるたびに外部APIは呼びません)
- 実質価格の「最安」の判定には、v20 の「あなたのステータス」を使います
- 「お得」は記録が7日分たまるまで出ません(自動取得を始めてから約1週間後から)

## 手順
1. Supabase の SQL Editor に `sql/v22-top.sql` を全部貼って Run(最後に「候補の数」が出ればOK。自動取得の前は0でOK)
2. GitHub に **app フォルダ(丸ごと)・lib フォルダ・sql フォルダ** をドラッグ&ドロップ → Commit
3. Vercel が Ready になったら、ホームでタブが出ることを確認
