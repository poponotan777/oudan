# オウダン v21:商品まとめ(運営だけが作る・3テンプレート・OGP画像の自動生成)

## できること
- `/collections`(合言葉が必要)で、運営だけがまとめを作れます
  1. テンプレートを選ぶ:**TOP N(順位つき)/ 横並び N選 / 比較リスト**
  2. タイトル・サブタイトル・本文を入れる
  3. 自動取得したDBから商品を探して **2〜6個** 追加(3サイトの価格つきで出ます)
  4. 並び替え・見出し(30字)・ひとこと解説
  5. 「OGP画像をプレビュー」→「保存」で **公開URL(/c/xxxx)** と **OGP画像(1200×630)** が自動でできる。「Xで投稿する」ボタンつき(#PR入りの文を用意)
- 公開ページ `/c/xxxx`:今の3サイト価格(作成時の価格も小さく表示)・購入ボタン・各商品ページ(/p/…)へのリンク
- 一覧ページ `/c`、サイトマップにも自動で載ります
- **商品ページ(/p/…)にもOGP画像**ができました(3サイトの価格を大きく並べ、最安を強調)。Xに商品ページのURLを貼るだけで価格比較のカードになります

## OGP画像の決まりごと(規約対応)
- 文字はすべて**商品画像の外**に置いています(楽天:商品画像に文字を重ねない)
- **Amazonの商品画像は使いません**(加工・保存が認められていないため)。楽天・Yahoo!の画像が無い商品は「画像なし」の枠になります
- 価格は必ず3サイトを並べ、「◯時点の価格(変動します)」と「PR」を入れています
- リンクはすべて運営のID(楽天アフィリエイト・バリューコマース・`popo-kaiteki-22`)

## 手順(SQL → 環境変数 → アップロード)
### ① SQL
Supabase の SQL Editor に `sql/v21-collections.sql` を全部貼って Run(最後に7つの列名が出ればOK)

### ② Vercel の環境変数を追加
| 変数名 | 値 |
|---|---|
| `ADMIN_KEY` | まとめ作成の合言葉(長めの好きな文字列。**ブラウザには配られません**) |

※ 未設定の間は、これまでの `NEXT_PUBLIC_CRAWL_KEY` でも入れます(移行期間用)。設定したら以後は `ADMIN_KEY` だけが有効です

### ③ GitHub にアップロード
**app フォルダ(丸ごと)・lib フォルダ・sql フォルダ・assets フォルダ** をドラッグ&ドロップ → Commit
- `assets/fonts` はOGP画像の日本語フォント(Noto Sans JP の一部の文字だけを入れたもの・約2.7MB・無料で再配布できるライセンス OFL.txt 同梱)です。必ず一緒に上げてください

### ④ 確認
1. `https://oudan.vercel.app/collections` → 合言葉 →「+ 新しく作る」
2. 商品を2つ以上追加 →「OGP画像をプレビュー」で画像が出る →「保存して公開URLを作る」
3. 公開URLを開く → 3サイトの価格が並ぶ
4. `公開URL/opengraph-image` を開くと画像が出る(Xに貼るとこの画像のカードになります)
5. 商品ページも同じく `/p/…/opengraph-image` で画像が出る

## 「アフィリエイトのIDを持っている人が、自分のIDで使う」について
- オウダンのサイト上で、他の人のIDやAPIキーを使ってリンクを出すことは、各社の規約上できません
  (Amazon:APIの認証情報を他人に渡す・使わせるのは禁止/楽天:1サイトに複数アカウントのリンクを置けない・リンクの改変禁止/バリューコマース:他人のメディアへの掲載は事前承認が必要)
- 代わりに、**このコード一式を、その人が自分の環境で動かせば、その人のIDで動きます**(IDやキーはすべて環境変数から読む作りにしています)
  1. GitHub でリポジトリをコピー(フォーク)
  2. 自分の Supabase・Vercel・GitHub Actions を用意し、`sql` を順に実行
  3. 環境変数・Secrets に **自分の** 楽天アプリID/アフィリエイトID、Yahoo! Client ID、バリューコマース sid/pid、Amazon Creators API(自分のアカウントで利用条件を満たしたもの)とタグを入れる
  4. `.github/workflows/collect.yml` の `AMAZON_PARTNER_TAG` と `SITE_ORIGIN` を自分のものに変える
  → その人のサイトで作ったまとめ・OGP画像のリンクは、すべてその人のIDになります
- 楽天の「競合サービス」条項(楽天ROOM等)は引き続き問い合わせ推奨です。回答次第で `lib/featureFlags.js` の `COLLECTIONS_ON` を false に戻せば止まります
